# Weekly Contracts 0.1.4 Verification

The controller-approved Weekly Contracts 0.1.3 candidate was tested on Super Fantasy Kingdom 0.8.070 in the portfolio’s Test - Mods profile. Slot 67 also verified native Save and fresh Continue with copied Human and Undead saves. It retained the accepted terms, deadline, the six-unit payment, three pending relic choices, and one settled relic award per kingdom.

Thunderstore already listed 0.1.3 with an earlier gameplay DLL. The release increments the project, BepInEx plugin, and Thunderstore manifest versions to 0.1.4. Mono.Cecil comparison against the approved DLL matched 196 managed methods, nine embedded resources, and the referenced assemblies. The comparison covered signatures, instructions, exception handlers, and managed metadata while allowing the version fields and generated PE and debug identity to change.

All 105 contract checks passed. The package verifier checked all six ZIP entries, dependency declarations, the icon, the plugin GUID and version, and the installed 0.8.070 save target. The README pins the two approved gameplay screenshots and 14 contract card PNGs to commit `372f0aa4c64d00f72d3d1e3aebcae762aa32f169`.
